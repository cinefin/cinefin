# Command-provider plugins

Each file (or package) here adds a kind of action Cinefin commands can run —
Wake-on-LAN, MQTT, a projector protocol. They ship with Cinefin and load
automatically; add one by pull request.

The contract, rules and submission checklist are in
[docs/PLUGINS.md](../../docs/PLUGINS.md). `wake_on_lan.py` is a complete example.
